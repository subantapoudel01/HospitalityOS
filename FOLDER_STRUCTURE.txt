--------------------------------------------------------------------------------
THE ONE RULE THAT KEEPS THIS HONEST
--------------------------------------------------------------------------------
Dependencies point one way: modules -> platform -> core.

  app/modules/receptionist/  MAY import from  app/platform/ and app/core/
  app/platform/              MAY import from  app/core/  only
  app/platform/              MUST NOT import from  app/modules/*

The moment platform imports from a module, the module is no longer removable
and the next module has to fork hotel/room data instead of sharing it.
